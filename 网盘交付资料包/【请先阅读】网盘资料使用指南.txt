二、 极速运行代码指引
-----------------------------------------------------------------------------
1. 打开终端（Terminal / CMD / PowerShell），进入【05_企业级可运行源码库】目录；
2. 确保电脑已安装 Python 3.10+，执行任意脚本即可见证控制台动态推理效果：
   $ python 01_fastapi_sse_stream.py
   $ python 02_native_react_engine.py
   $ python 05_hybrid_rag_pipeline.py
   $ python 06_langgraph_workflow.py
   $ python 07_medical_triage_disambiguate.py
   $ python 08_circuit_breaker.py

三、 搭建您自己的专属网站与全球上线
-----------------------------------------------------------------------------
如果您希望把这套文档上线为您自己的个人技术站点：
1. 进入【04_VitePress知识库源码】目录；
2. 执行 `npm install` 安装依赖，然后运行 `npm run docs:dev` 即可本地启动浏览；
3. 执行 `npm run docs:build` 打包静态站点；
4. 运行 `wrangler pages deploy docs/.vitepress/dist --project-name=ai-agent-tutorial`
   即可免费部署到 Cloudflare 全球 CDN，获得专属公网访问链接！
